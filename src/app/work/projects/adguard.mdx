## 맥락

화장품 광고 문구의 과대·허위 표현을 미리 점검하는 팀 프로젝트였습니다. 기존 방식처럼 위반 여부만 알려주면 마케터는 결국 안전한 문장을 다시 찾느라 <mark>작업이 또 멈춥니다.</mark>

## 한 일

- 팀장으로 서비스 범위를 위반 판정에서 대체 문구 추천과 재검증까지 넓혔습니다.
- 화장품 관련 법령과 심의 데이터를 모아 검색 기반을 만들었습니다.
- 규칙 엔진, 근거 검색, 판정, 대안 생성, 재검증으로 이어지는 5단계 흐름을 설계했습니다.
- 잘려 나간 법령 조항의 맥락을 살리려고 문서를 의미 단위로 다시 나눠 근거 1,069개를 만들었습니다.

## 판단

법령을 일정 길이로 자르자 조항 앞뒤가 끊겨 엉뚱한 근거가 검색됐습니다. 시간이 더 들더라도 <mark>의미 단위로 다시 나누는 쪽</mark>을 택했습니다. 생성된 대체 문구 역시 다시 위험할 수 있어서 마지막에 재검증 단계를 한 번 더 두었습니다.

## 결과

- 의미 단위로 다시 만든 법령 근거 1,069개
- 규칙 엔진 테스트 25건 중 24건 정확
- 내부 통합 테스트 10건 중 9건 정확

## 남은 것

내부 테스트 정확도는 확인했지만, 실제 마케터가 썼을 때 문구 수정 시간이 얼마나 줄어드는지는 재지 못했습니다. 다음에는 실사용자 테스트를 일정 앞쪽에 넣으려 합니다.
